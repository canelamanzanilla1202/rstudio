# Thematic Mapping of Puno Province, Peru

Geospatial analysis and thematic mapping of district-level population using R, GIS, and data from Peru's 2017 National Census.

## Project Overview
This project explores spatial population distribution in Puno Province, Peru, through interactive choropleth mapping and hexagonal grid visualization.

## Technologies
- R and RStudio
- R Markdown
- sf and dplyr
- ggplot2 and ggspatial
- Leaflet
- OpenStreetMap

## Project Outputs
- Interactive choropleth map of district populations
- Static hexagonal grid map
- Population summary table
- HTML report

## Files
- `puno_geomaga.Rmd`: R Markdown source code
- `puno_geomaga.html`: Generated report

## Data Source
Peru's National Institute of Statistics and Informatics (INEI), 2017 Census.
